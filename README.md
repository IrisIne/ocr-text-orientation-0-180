# OCR Text Orientation

Решение задачи определения ориентации текстового кропа. Для каждого изображения нужно оценить `p_180` - вероятность того, что текст перевернут на 180°.

Итоговый результат:

- `1 - Brier Score = 0.98498937`;
- `Brier Score = 0.01501063`.

## Подход

Используется небольшой классификатор ориентации PaddleOCR. Каждое изображение проверяется в исходном виде и после поворота на 180°, затем ответы симметризуются.

Вторая часть строится по уверенности OCR: правильно ориентированный текст обычно распознается увереннее. Оба признака объединяются моделью с двумя коэффициентами, обученными по ошибке Брайера с L2-регуляризацией на публичных OCR-кропах.

## Ход экспериментов

Сначала была обучена MobileNetV3-Small на синтетических данных. Она хорошо работала на синтетической выборке, но на платформе получила `0.75366686`.

Готовый классификатор PaddleOCR дал `0.97401135`. Проверка предобработки показала, что полный кроп лучше нескольких окон фиксированной ширины. Калибровка по температуре отдельно не помогла, зато добавление по уверенности OCR снизило ошибку с `0.02598865` до `0.01501063`.

Классификатор обработал 20_000 кропов примерно за шесть минут на CPU Colab. OCR оказался заметно медленнее, но дал основной прирост качества. Его можно запускать только на неуверенных примерах.
